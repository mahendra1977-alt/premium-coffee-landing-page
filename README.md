# premium-coffee-landing-page
A premium coffee shop landing page designed with HTML, CSS, and JavaScript, demonstrating responsive web design, modern UI principles, and interactive front-end development skills.
Designed with a focus on performance, usability, and aesthetics, this landing page provides an immersive browsing experience across desktop, tablet, and mobile devices.

---

## 🌟 Overview

Verdant Roast is a front-end web project that demonstrates modern web design principles and responsive development practices. It combines clean code architecture with an attractive interface to create a professional coffee shop landing page suitable for portfolio showcases, learning purposes, and UI inspiration.

---

## ✨ Key Features

- Modern and elegant landing page design
- Fully responsive layout for all screen sizes
- Sticky navigation bar
- Hero section with featured product
- Interactive coffee menu cards
- About section
- Gallery section
- Customer testimonials
- Contact form
- Smooth scrolling navigation
- Glassmorphism UI components
- Hover animations and transition effects
- Professional typography and spacing
- Clean, organized, and maintainable code

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/verdant-roast-landing-page.git
```

### Navigate to the Project Directory

```bash
cd verdant-roast-landing-page
```

### Run the Project

Open the `index.html` file in your preferred browser.

For the best development experience, use the **Live Server** extension in Visual Studio Code.
